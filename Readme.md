# ☕ Java Core to Advanced Programming

A beginner-friendly Java programming repository containing simple examples to understand Java concepts step by step.

This repository is part of my Java learning journey. It includes practical programs covering fundamental programming concepts, control statements, loops, arrays, and object-oriented programming.

- Learn Java programming from the basics.
- Understand programming concepts through simple code examples.
- Practice writing and executing Java programs.
- Build a foundation for object-oriented programming (OOP).
- Improve problem-solving and programming skills.

## 🚀 Getting Started

### Prerequisites

Install the Java Development Kit (JDK) on your computer.

Check whether Java is installed by running:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/Trusha-Bhardava/java-core-to-advance-program.git
```

### Open the Project

```bash
cd java-core-to-advance-program
```

Open the folder in your preferred code editor, such as VS Code, IntelliJ IDEA, or Eclipse.

## ▶️ How to Run a Java Program

For example, to run the array example:

```bash
javac array.java
java array
```

You can use the same process for other files by replacing the filename and class name as appropriate.

**Note:** The Java source filename and public class name must match, including capitalization. Some examples may use a different class name from the filename, so check the class declaration before running them.

## 💡 Learning Approach

To get the most out of these examples:

1. Read the code carefully.
2. Understand what each statement does.
3. Compile and run the program.
4. Observe the output.
5. Change some values and run it again.
6. Try writing the program yourself without looking at the original code.
